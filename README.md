# Task-Management-System
This is a website for a task management system, which offers users the calendar, habit tracker, Eisenhower matrix and to-do list to manage their daily routine, work, study or other activities efficiently.
Also, the user can create notes right on this web-app and manage their goals (beta features).
Furthermore, it's possible to create personalised notifications, change the theme of the app and the style and time zone.

The stack for this app consists of Flask, React + TS, Turso

To run the app locally, you need: 
```
.env:
VITE_API_URL
DB_LINK
DB_AUTH_TOKEN
```
<li> check out package.json and run <i>npm installDep</i> to install the required dependancies </li>
<li>run <i>npm start</i> to run the app locally</li>
